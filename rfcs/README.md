# RFCs

Change proposals for `agent-iam-spec`.

## Process

1. Open an issue describing the problem.
2. Copy `RFC-TEMPLATE.md` to `NNNN-short-title.md`, using the next available number.
3. Fill in the template and open a pull request.
4. Discussion period: minimum 14 calendar days for normative changes.
5. Maintainers record the decision in the document's Decision section.
