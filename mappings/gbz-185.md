# GB/Z 185 对齐说明

状态：国家标准对齐，待全文审阅  
更新日期：2026-09-22

## 1. 状态声明

中国国家市场监督管理总局、国家标准化管理委员会于 2026-05-22 发布 `GB/Z 185-2026《人工智能 智能体互联》` 系列：

| 标准号 | 名称 | 状态 |
|---|---|---|
| `GB/Z 185.1-2026` | 第 1 部分：总体架构 | 现行 |
| `GB/Z 185.2-2026` | 第 2 部分：身份码 | 现行 |
| `GB/Z 185.3-2026` | 第 3 部分：身份管理 | 现行 |

`GB/Z` 是国家标准化指导性技术文件，不是强制性 `GB`，也不同于推荐性 `GB/T`。

核验入口：<https://std.samr.gov.cn/>

## 2. 重要限制

## 4. 外部标识保存格式

第 2 部分第 4.6 节要求：如部署需要兼容 `GB/Z 185.2-2026` 身份码，应保存为带命名空间和签发方的外部标识，不得仅凭外部代码覆盖本地 Agent Identity。

```json
{
  "type": "gbz185_identity_code",
  "issuer": "<verified issuing authority>",
  "value": "<identity code>"
}
```

## 5. 系列部分与 GB/Z 185 的对应（待验证）

Agent IAM 系列采用多部分结构，与 `GB/Z 185` 的部分划分存在方向性对应，但**不是**一对一关系：

| Agent IAM Series | GB/Z 185 | 关系 |
|---|---|---|
| Part 1 总体架构与术语 | `GB/Z 185.1-2026` 总体架构 | 方向一致 |
| Part 2 注册与发现（含标识/身份码） | `GB/Z 185.2-2026` 身份码 | 部分对应；本系列另含发现 |
| Part 3 身份与认证（含身份管理生命周期） | `GB/Z 185.3-2026` 身份管理 | 部分对应；本系列拆分认证与授权 |
| Part 4 授权与委托 | 无直接对应部分 | `GB/Z 185` 未按此拆分 |
| Part 5–7 联邦/审计/一致性 | 无直接对应部分 | 本系列扩展 |

上述对应为结构假设，**不得**在获得全文并逐条审阅前作为兼容性结论。
