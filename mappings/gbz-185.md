# GB/Z 185 对齐说明

状态：国家标准对齐，待全文审阅  
更新日期：2026-09-22

## 1. 状态声明

中国国家市场监督管理总局、国家标准化管理委员会于 2026-05-22 发布 `GB/Z 185-2026《人工智能 智能体互联》` 系列：

| 标准号 | 名称 | 状态 |
|---|---|---|
| `GB/Z 185.1-2026` | 第 1 部分：总体架构 | 现行 |
| `GB/Z 185.2-2026` | 第 2 部分：身份码 | 现行 |
| `GB/Z 185.3-2026` | 第 3 部分：身份管理 | 现行 |

`GB/Z` 是国家标准化指导性技术文件，不是强制性 `GB`，也不同于推荐性 `GB/T`。

核验入口：<https://std.samr.gov.cn/>

## 2. 重要限制

本仓库尚未获得并逐条审阅 `GB/Z 185` 全文。因此：

- **不得**根据标准名称推定字段级兼容；
- **不得**声称 `agent-iam-spec` 已符合或实现 `GB/Z 185`；
- 任何兼容性声明必须形成独立的字段映射表并给出条款引用。

## 4. 外部标识保存格式

规范第 6.5 节要求：如部署需要兼容 `GB/Z 185.2-2026` 身份码，应保存为带命名空间和签发方的外部标识，不得仅凭外部代码覆盖本地 Agent Identity。

```json
{
  "type": "gbz185_identity_code",
  "issuer": "<verified issuing authority>",
  "value": "<identity code>"
}
```
